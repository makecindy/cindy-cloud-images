# 云主机制镜机维护

Cindy 在腾讯云新加坡长期保留一台包月制镜机，Host 和桌面版共用，按月自动续费。发布后保留实例供下次更新使用。用户开通云主机时，交付服务使用所在地区已经发布的镜像，制镜机可以独立停机维护。

## 更新镜像

1. 更新 Ubuntu、Cindy Host、桌面或预装浏览器时，分别从干净的 Ubuntu 24.04 系统制作对应版本。复用实例，每次准备干净的构建盘。系统盘大小应兼容该版本支持的最小套餐。
2. 按[构建说明](../README.md)验证发行包摘要，在停止写入的构建盘上封存。正式镜像使用正式服的认证和设备注册配置。验证新主机能绑定购买者自己的企业账号，桌面版还要验证浏览器可以打开。
3. 从新加坡将通过验收的镜像复制到产品支持的全部地区。逐地区核对 Host 和桌面的镜像状态、系统盘兼容性及免费配额，在部署系统登记每个地区的镜像 ID、版本和验收结果。保留上一版供新订单回滚。

## 日常维护

- 在腾讯云按制镜机名称和实例 ID 核对资产、套餐金额、自动续费状态及下次到期日。维护负责人交接时一并移交这项检查。
- 每月核对续费和镜像配额，检查 Ubuntu、Cindy 和浏览器是否有需要重新制镜的更新。发生续费失败、镜像失效或地区缺少任一版本时，记录具体实例或地区，及时处理。
- 用户试用机按各自订单管理。制镜机从日常试用资源清理中排除；需要退役时单独决定。凭据和生产资产编号保存在相应的凭据库和部署记录中。
